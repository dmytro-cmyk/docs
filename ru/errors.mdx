## HTTP-коды ответа

| Код | Описание |
|------|-------------|
| `200` | Успешно |
| `201` | Ресурс создан |
| `204` | Успешно, без содержимого |
| `401` | Не авторизован — токен неверный или не передан |
| `403` | Доступ запрещён — нет прав |
| `404` | Не найдено — ресурса не существует |
| `413` | Слишком большой запрос — файл превышает лимит размера |
| `422` | Ошибка валидации — подробности в поле `errors` |
| `429` | Превышен лимит запросов — смотрите заголовок `Retry-After` |
| `502` | Ошибка шлюза — сбой внешнего сервиса (Telegram) |

## Формат ответа с ошибкой

```json
{
  "message": "The given data was invalid.",
  "errors": {
    "field_name": [
      "The field_name is required."
    ]
  }
}
```

Тексты ошибок в ответах API всегда на английском.

## Бизнес-ошибки

Когда запрос корректен, но действие невозможно, рядом с `message` приходит машиночитаемый `code`:

| Код | Статус | Значение |
|------|--------|---------|
| `unauthorized` | `403` | У пользователя нет права на это действие |
| `not_found` | `404` | Сущности нет в этом боте |
| `conflict` | `409` | Дубль или текущее состояние не позволяет выполнить действие |
| `limit_exceeded` | `422` | Ограничение тарифа не позволяет выполнить действие |
| `quota_exceeded` | `422` | Достигнут защитный лимит на количество сущностей (`limit` в ответе) |
| `pro_required` | `422` | Действие доступно на тарифе Pro |

Ошибка `pro_required` дополнительно возвращает `current_plan` (Pro, Basic, Trial или `null` без активной подписки) и `upgrade_url` — страницу кабинета, где можно обновить тариф:

```json
{
  "message": "This action is available on the Pro plan. Upgrade your plan to continue.",
  "code": "pro_required",
  "current_plan": "Basic",
  "upgrade_url": "https://app.zenedu.io/workspace/billing"
}
```

## Лимит запросов

Количество запросов к API ограничено. При превышении лимита API возвращает код `429` и заголовок `Retry-After` — через сколько секунд можно повторить запрос.

## Ошибки Telegram

При отправке сообщений через API Telegram может вернуть ошибки:

| Код | Значение |
|------|---------|
| `422` | Подписчик заблокировал бота или неактивен |
| `429` | Лимит Telegram — соблюдайте заголовок `Retry-After` |
| `502` | Ошибка авторизации в Telegram или сбой доставки сообщения |
