---

API v1 использует авторизацию по Bearer-токену.

## Где взять токен

API-токен находится в личном кабинете Zenedu: **Настройки → Проект → API и вебхуки**. Если сбросить токен, предыдущий перестанет работать. Храните токен в секрете: он даёт полный доступ к вашему аккаунту.

Этот же токен используется для [MCP-сервера](/ru/mcp) ИИ-агентов.

## Как передавать токен

Передавайте токен в заголовке `Authorization` в каждом запросе:

```bash
curl -X GET https://app.zenedu.io/api/v1/bots \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Accept: application/json"
```

<Warning>
  Заголовок `Accept: application/json` обязателен для всех запросов к API v1. Запросы без него отклоняются.
</Warning>
