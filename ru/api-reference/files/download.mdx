---
title: "Скачать файл"
description: "Скачивает файл, приложенный к сообщению"
openapi: "GET /api/v1/bot/{bot}/file/{message}"
---

При ограничении частоты запросов Telegram возвращается `429` с заголовком `Retry-After`, содержащим время ожидания в секундах. Если другой запрос ещё получает файл, возвращается `503` с `Retry-After: 1`. Повторите запрос после указанной задержки. Эти временные ошибки не кешируются.
