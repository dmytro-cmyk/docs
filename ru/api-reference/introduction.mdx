## Базовый URL

Все эндпоинты API v1 используют базовый URL:

```
https://app.zenedu.io/api/v1
```

## Авторизация

API v1 использует авторизацию по Bearer-токену. Передавайте токен в каждом запросе:

```bash
curl -X GET https://app.zenedu.io/api/v1/bots \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Accept: application/json"
```

<Warning>
  Заголовок `Accept: application/json` обязателен для всех запросов к API v1.
</Warning>

API-токен находится в личном кабинете Zenedu: **Настройки → Проект → API и вебхуки**. Там его можно посмотреть и скопировать в любой момент. Если сбросить токен, предыдущий перестанет работать.

## Пагинация

Эндпоинты-списки возвращают постраничные ответы с полями `data`, `links` и `meta`. Размер страницы задаётся параметром `per_page` (по умолчанию 30).
