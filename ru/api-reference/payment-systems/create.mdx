---
title: "Создать способ оплаты"
description: "Создаёт способ оплаты в аккаунте"
openapi: "POST /api/v1/payment-systems"
---

Создаёт способ оплаты указанного `type`.

- Ключи `settings` зависят от `type`, см. таблицу в поле `settings`. Неизвестные ключи отбрасываются, у текстовых значений обрезаются пробелы.
- `name` должен быть уникальным в аккаунте без учёта регистра.
- В аккаунте может быть только один способ оплаты `telegramstars`: на второй вернётся `409`.
- Для `manually` у реквизитов обязательны `name` и `value`, а итоговое сообщение бота должно уложиться в 4000 символов.
- `attach_to_all_offers` добавляет способ оплаты во все тарифы, чью валюту и минимальную сумму он поддерживает.

<Warning>
Для `stripe` перед сохранением в Stripe регистрируется вебхук с переданным `secret_key`. Если Stripe отклоняет ключ, ничего не сохраняется и возвращается `422` с ошибкой в `settings.secret_key`.
</Warning>

При создании способа оплаты Stripe или изменении `secret_key` ключ после обрезки пробелов по краям должен начинаться с `sk_` или `rk_`, содержать непустое значение после префикса и не содержать пробельных символов. Фиксированная длина не проверяется. При неверном формате возвращается `422` с ошибкой в `settings.secret_key` до обращения к Stripe. Подлинность ключа и его права по-прежнему проверяет Stripe при регистрации вебхука. Неизменённый сохранённый ключ повторно не проверяется.

Для `stripe` параметры `settings.automatic_tax` и `settings.collect_billing_address` — независимые необязательные логические значения, по умолчанию оба выключены. Налог добавляется сверху стоимости. Существующие подписки сохраняют прежние условия. Адрес доступен в деталях заказа и экспорте заказов, но не в профиле подписчика. Перед включением автоматического налога настройте Stripe Tax и налоговые регистрации в Stripe. Изменение этих параметров не пересоздаёт вебхук Stripe; при обновлении пропущенные ключи сохраняют свои значения.

Ответ содержит оба флага Stripe в `settings` как логические значения. Отсутствующие сохранённые значения возвращаются как `false`.
