---
title: "Изменить порядок способов оплаты"
description: "Задаёт порядок отображения способов оплаты"
openapi: "PUT /api/v1/payment-systems/order"
---

Задаёт порядок отображения способов оплаты и возвращает список в новом порядке. Каждый ID должен принадлежать этому аккаунту, иначе возвращается `422` и порядок не меняется.
