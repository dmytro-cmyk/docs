---
title: "Изменить порядок платёжных систем"
description: "Задаёт порядок отображения платёжных систем"
openapi: "PUT /api/v1/payment-systems/order"
---

Задаёт порядок отображения платёжных систем и возвращает список в новом порядке. Каждый ID должен принадлежать этому аккаунту, иначе возвращается `422` и порядок не меняется.
