---
title: "Список типов платёжных систем"
description: "Возвращает типы платёжных систем и настройки, которые принимает каждый"
openapi: "GET /api/v1/payment-systems/types"
---

Возвращает все типы платёжных систем с ключами `settings`, которые принимает каждый. Код `type` используйте при создании платёжной системы.
