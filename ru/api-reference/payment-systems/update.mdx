---
title: "Обновить платёжную систему"
description: "Частично обновляет платёжную систему"
openapi: "PATCH /api/v1/payment-systems/{paymentSystem}"
---

Частично обновляет платёжную систему: меняются только переданные поля.

- `type` изменить нельзя, он игнорируется.
- `settings` объединяются с сохранёнными по ключам, поэтому можно поменять один ключ, не передавая данные доступа заново. `manualTextRequisites` заменяется целым списком.
- `public_name: null` или пустая строка сбрасывает название для подписчиков на название типа.

<Warning>
Для `stripe` вебхук регистрируется заново только при смене `secret_key`. Если Stripe отклоняет новый ключ, ничего не сохраняется и возвращается `422` с ошибкой в `settings.secret_key`.
</Warning>
