---
title: "Получить платёжную систему"
description: "Возвращает одну платёжную систему по ID"
openapi: "GET /api/v1/payment-systems/{paymentSystem}"
---

Возвращает одну платёжную систему аккаунта. На платёжную систему другого аккаунта вернётся `404`.

Данные доступа никогда не возвращаются: автоматические типы сообщают только `credentials_set`.
