---
title: "Получить способ оплаты"
description: "Возвращает один способ оплаты по ID"
openapi: "GET /api/v1/payment-systems/{paymentSystem}"
---

Возвращает один способ оплаты аккаунта. На способ оплаты другого аккаунта вернётся `404`.

Данные доступа никогда не возвращаются: автоматические типы сообщают только `credentials_set`.
