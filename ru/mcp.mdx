title: "MCP-сервер"
description: "Подключите ИИ-агентов к аккаунту Zenedu через Model Context Protocol"
---

Zenedu предоставляет [MCP](https://modelcontextprotocol.io)-сервер для ИИ-агентов. Подключённый агент может создавать курсы и воронки, управлять подписчиками и доступами, тарифами, заказами, рассылками, автоматизациями и настройками ботов. Агент сможет выполнить любое действие, которое раньше вы делали руками в кабинете.

## Адрес

```
https://app.zenedu.io/mcp
```

Транспорт: Streamable HTTP.

## Быстрая настройка

Скопируйте промпт и отправьте его своему ИИ-агенту: Claude, ChatGPT, Cursor или любому другому. Агент сам добавит сервер, вам останется подтвердить подключение и войти в Zenedu.

```
Добавь MCP-сервер Zenedu https://app.zenedu.io/mcp
```

## Авторизация

Добавьте адрес как коннектор в своём клиенте. При первом подключении клиент откроет страницу Zenedu: войдите, выберите проект и нажмите **Разрешить**. Агент будет работать в пределах ваших прав в этом проекте. Любой клиент с поддержкой OAuth для MCP подключается так же.

Все подключения видны в личном кабинете: **Настройки → Аккаунт → MCP**, там же любое из них можно отозвать.

## Подключение клиента

    Включите режим разработчика в **Settings → Apps & Connectors → Advanced settings**, затем создайте коннектор с адресом `https://app.zenedu.io/mcp` и аутентификацией *OAuth* и разрешите доступ.

    **Codex**, агент ChatGPT для терминала и IDE:


    Инструменты появятся в каждой сессии Codex, в CLI и в расширении для IDE.

## Что умеет агент

Агент умеет работать с теми же операциями, которые доступны в кабинете: боты и их настройки, приложение, курсы с модулями и уроками, воронки с шагами и кнопками, подписчики, теги и дополнительные поля, тарифы и промокоды, заказы и подписки, рассылки, автоматизации, каналы и группы, партнёрка, команды бота, вебхуки, способы оплаты, загрузка файлов и изображений.

## Права и безопасность

Агент получает доступ к тем операциям, которые есть у пользователя в проекте.

Сотрудникам доступны инструменты в рамках тех доступов, которые им предоставлены на платформе.

Удаление, остановка и другие необратимые действия помечены на стороне сервера как разрушающие: агент переспросит вас перед выполнением. Если клиент поддерживает подтверждение вызовов, оставьте его включённым для таких действий.

## Подключения и отзыв

В разделе **Настройки → Аккаунт → MCP** видны все ваши подключения: название клиента, статус, дата создания и время последнего вызова. Любое подключение можно отозвать, после этого клиент потеряет доступ и попросит войти заново.

Доступ выдаётся на сутки и продлевается клиентом автоматически, без повторного входа. Если подключением не пользовались 90 дней, оно истекает и помечается в списке. Такое подключение можно отозвать, а чтобы продолжить работу, подключитесь заново.

Одно подключение даёт доступ к одному проекту. Чтобы агент работал с несколькими проектами, подключите сервер для каждого отдельно.

## Первые шаги

После подключения попросите агента показать ваши боты. Так вы проверите, что доступ работает, а агент узнает, с каким ботом работать дальше: все остальные действия привязаны к конкретному боту.

Что полезно знать заранее:

- Новые курсы и воронки создаются выключенными, новые уроки скрытыми. Агент проверит результат и включит их только по вашей просьбе.
- Шаги воронки не отправляются подписчикам сами по себе, пока не задано время отправки.
- Перед выполнением деструктивных операций агент переспросит.

Примеры задач, с которых удобно начать:

```
Покажи мои боты
```

```
Создай курс «Основы продаж» из трёх модулей по два урока в каждом, тариф 49 EUR с доступом навсегда
```

```
Создай воронку из трёх приветственных сообщений с задержкой в один день между ними
```

```
Сделай рассылку всем, кто не купил курс за последние 30 дней
```

## Решение проблем

| Что происходит | Что сделать |
|---|---|
| После входа инструменты не появились | Перезапустите сессию или обновите список MCP-серверов в клиенте. В Claude Code выполните `/mcp`, в Cursor нажмите **Refresh** рядом с `zenedu`. |
| Клиент пишет «Unauthorized» или снова просит войти | Подключение отозвано или истекло. Удалите коннектор в клиенте и добавьте заново. |
| ChatGPT не даёт добавить коннектор | Включите режим разработчика в **Settings → Apps & Connectors → Advanced settings**. На тарифах Business, Enterprise и Edu коннекторы включает администратор рабочего пространства. |
| Агент говорит, что у него нет нужного инструмента | У вас нет доступа к этой операции в проекте. Попросите владельца проекта расширить доступы. |
| Агент работает не с тем проектом | Проект выбирается при подключении. Отзовите подключение в **Настройки → Аккаунт → MCP** и подключитесь заново, выбрав нужный проект. |

## Вопросы и ответы

**Можно ли подключить несколько клиентов?**

Да. Каждый клиент подключается отдельно, все подключения видны в кабинете.

**Могут ли сотрудники подключать своих агентов?**

Да, каждый сотрудник подключается сам под своим входом и получает свои права. Владелец видит только свои подключения.

**Агент может что-то сломать?**

Агент выполняет только те операции, которые доступны вам в проекте, и переспрашивает перед деструктивными операциями. Новое создаётся выключенным, пока вы не проверите.

**Это платно?**

Нет, MCP-сервер входит в ваш тариф Zenedu. Оплата клиента, например Claude или ChatGPT, зависит от его условий.

**Как отключить агента?**

Откройте **Настройки → Аккаунт → MCP** и отзовите подключение. Клиент сразу потеряет доступ.
