---
title: "Update payment method"
description: "Partially updates a payment method"
openapi: "PATCH /api/v1/payment-systems/{paymentSystem}"
---

Partially updates a payment method: only sent fields change.

- `type` cannot be changed and is ignored.
- `settings` are merged over the stored ones by key, so a single key can be changed without resending credentials. `manualTextRequisites` is replaced as a whole list.
- `public_name: null` or an empty string resets the subscriber-facing name to the type name.

<Warning>
For `stripe`, the webhook is registered again only when `secret_key` changes. If Stripe rejects the new key, nothing is saved and `422` is returned with the error under `settings.secret_key`.
</Warning>

For `stripe`, `settings.automatic_tax` and `settings.collect_billing_address` are independent optional booleans, both disabled by default. Tax is added on top of the price. Existing subscriptions keep their original terms. The address is available in order details and order exports, not in the subscriber profile. Configure Stripe Tax and tax registrations in Stripe before enabling automatic tax. Updating these options does not recreate the Stripe webhook; omitted keys keep their stored values.
