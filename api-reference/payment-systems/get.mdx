---
title: "Get payment method"
description: "Returns a single payment method by ID"
openapi: "GET /api/v1/payment-systems/{paymentSystem}"
---

Returns a single payment method of the account. A payment method of another account returns `404`.

Credentials are never returned. Automatic types expose `credentials_set` and applicable public payment settings. Full `settings` are returned for `manually` (texts and requisites) and `telegramstars` (`bot_only`); an empty set comes as an empty array `[]`.

For `stripe`, `settings` always includes `automatic_tax` and `collect_billing_address` as booleans. If a connection has no stored values, both are `false`. Secret keys and webhook secrets are never included.
