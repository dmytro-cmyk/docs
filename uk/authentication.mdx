title: "Авторизація"

---

API v1 використовує авторизацію за Bearer-токеном.

## Де взяти токен

API-токен знаходиться в особистому кабінеті Zenedu: **Налаштування → Проєкт → API та вебхуки**. Якщо скинути токен, попередній перестане працювати. Тримайте токен у секреті: він дає повний доступ до вашого акаунта.

Цей самий токен використовується для [MCP-сервера](/uk/mcp) ШІ-агентів.

## Як передавати токен

Передавайте токен у заголовку `Authorization` у кожному запиті:

```bash
curl -X GET https://app.zenedu.io/api/v1/bots \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Accept: application/json"
```

<Warning>
  Заголовок `Accept: application/json` обов’язковий для всіх запитів до API v1. Запити без нього відхиляються.
</Warning>
