---
title: "Авторизація"
description: "Як авторизуватися в Zenedu API"
---

API v1 використовує авторизацію за Bearer-токеном.

## Де взяти токен

API-токен знаходиться в особистому кабінеті Zenedu в розділі **Налаштування робочого простору → API і вебхуки**. Якщо скинути токен, попередній перестане працювати. Тримайте токен у секреті: він дає повний доступ до вашого акаунта.

## Як передавати токен

Передавайте токен у заголовку `Authorization` у кожному запиті:

```bash
curl -X GET https://app.zenedu.io/api/v1/bots \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Accept: application/json"
```

<Warning>
  Заголовок `Accept: application/json` обов’язковий для всіх запитів до API v1. Запити без нього відхиляються.
</Warning>

## Функції Pro

Деякі ендпоінти потребують активної підписки Pro. У документації вони позначені позначкою **Pro**. Виклик Pro-ендпоінта без активної підписки повертає помилку `403`.
