---
title: "MCP-сервер"
description: "Підключіть ШІ-агентів до акаунта Zenedu через Model Context Protocol"
---

Zenedu надає [MCP](https://modelcontextprotocol.io)-сервер для ШІ-агентів. Підключений агент може створювати курси та воронки, керувати підписниками й доступами, тарифами, замовленнями, розсилками, автоматизаціями та налаштуваннями ботів. Агент зможе виконати будь-яку дію, яку раніше ви робили руками в кабінеті.

## Адреса

```
https://app.zenedu.io/mcp
```

Транспорт: Streamable HTTP.

## Швидке налаштування

Скопіюйте промпт і надішліть його своєму ШІ-агенту: Claude, ChatGPT, Cursor або будь-якому іншому. Агент сам додасть сервер, вам залишиться підтвердити підключення та увійти в Zenedu.

```
Додай MCP-сервер Zenedu https://app.zenedu.io/mcp
```

## Авторизація

Додайте адресу як конектор у своєму клієнті. Під час першого підключення клієнт відкриє сторінку Zenedu: увійдіть, виберіть проєкт і натисніть **Дозволити**. Агент працюватиме в межах ваших прав у цьому проєкті. Будь-який клієнт із підтримкою OAuth для MCP підключається так само.

Усі підключення видно в особистому кабінеті: **Налаштування → Акаунт → MCP**, там же будь-яке з них можна відкликати.

## Підключення клієнта

<Tabs>
  <Tab title="Claude">
    **Claude Code**

    ```bash
    claude mcp add --transport http zenedu https://app.zenedu.io/mcp
    ```
    Потім виконайте `/mcp` у Claude Code, виберіть `zenedu` і увійдіть у Zenedu в браузері. Після цього попросіть Claude, наприклад: *«Покажи мої боти і створи воронку з трьома привітальними повідомленнями в першому».*

    **Claude Desktop і claude.ai**

    Відкрийте **Settings → Connectors → Add custom connector**, вкажіть назву `Zenedu` і адресу `https://app.zenedu.io/mcp`, потім натисніть **Connect** і дозвольте доступ.
  </Tab>
  <Tab title="ChatGPT">
    **ChatGPT у браузері та десктопі**

    Увімкніть режим розробника в **Settings → Apps & Connectors → Advanced settings**, потім створіть конектор з адресою `https://app.zenedu.io/mcp` і автентифікацією *OAuth* та дозвольте доступ.

    **Codex**, агент ChatGPT для термінала та IDE:

    ```bash
    codex mcp add zenedu --url https://app.zenedu.io/mcp
    codex mcp login zenedu
    ```

    Інструменти з’являться в кожній сесії Codex, у CLI та в розширенні для IDE.

        "zenedu": {
          "url": "https://app.zenedu.io/mcp"

## Що вміє агент

Агент уміє працювати з тими самими операціями, які доступні в кабінеті: боти та їхні налаштування, додаток, курси з модулями та уроками, воронки з кроками та кнопками, підписники, теги та додаткові поля, тарифи та промокоди, замовлення та підписки, розсилки, автоматизації, канали та групи, партнерка, команди бота, вебхуки, способи оплати, завантаження файлів і зображень.

## Права та безпека

Агент отримує доступ до тих операцій, які є в користувача в проєкті.

Співробітникам доступні інструменти в межах тих доступів, які їм надано на платформі.

Видалення, зупинка та інші незворотні дії позначені на боці сервера як руйнівні: агент перепитає вас перед виконанням. Якщо клієнт підтримує підтвердження викликів, залиште його ввімкненим для таких дій.

## Підключення та відкликання

У розділі **Налаштування → Акаунт → MCP** видно всі ваші підключення: назву клієнта, статус, дату створення та час останнього виклику. Будь-яке підключення можна відкликати, після цього клієнт втратить доступ і попросить увійти знову.

Доступ видається на добу й подовжується клієнтом автоматично, без повторного входу. Якщо підключенням не користувалися 90 днів, воно спливає й позначається у списку. Таке підключення можна відкликати, а щоб продовжити роботу, підключіться знову.

Одне підключення дає доступ до одного проєкту. Щоб агент працював із кількома проєктами, підключіть сервер для кожного окремо.

## Перші кроки

Після підключення попросіть агента показати ваші боти. Так ви перевірите, що доступ працює, а агент дізнається, з яким ботом працювати далі: усі інші дії прив’язані до конкретного бота.

Що корисно знати заздалегідь:

- Нові курси та воронки створюються вимкненими, нові уроки прихованими. Агент перевірить результат і ввімкне їх лише на ваше прохання.
- Кроки воронки не надсилаються підписникам самі по собі, доки не задано час надсилання.
- Перед виконанням деструктивних операцій агент перепитає.

Приклади завдань, з яких зручно почати:

```
Покажи мої боти
```

```
Створи курс «Основи продажів» із трьох модулів по два уроки в кожному, тариф 49 EUR із доступом назавжди
```

```
Створи воронку з трьох привітальних повідомлень із затримкою в один день між ними
```

```
Зроби розсилку всім, хто не купив курс за останні 30 днів
```

## Розв’язання проблем

| Що відбувається | Що зробити |
|---|---|
| Після входу інструменти не з’явилися | Перезапустіть сесію або оновіть список MCP-серверів у клієнті. У Claude Code виконайте `/mcp`, у Cursor натисніть **Refresh** біля `zenedu`. |
| Клієнт пише «Unauthorized» або знову просить увійти | Підключення відкликано або воно спливло. Видаліть конектор у клієнті та додайте знову. |
| ChatGPT не дає додати конектор | Увімкніть режим розробника в **Settings → Apps & Connectors → Advanced settings**. На тарифах Business, Enterprise та Edu конектори вмикає адміністратор робочого простору. |
| Агент каже, що в нього немає потрібного інструмента | У вас немає доступу до цієї операції в проєкті. Попросіть власника проєкту розширити доступи. |
| Агент працює не з тим проєктом | Проєкт обирається під час підключення. Відкличте підключення в **Налаштування → Акаунт → MCP** і підключіться знову, обравши потрібний проєкт. |

## Запитання та відповіді

**Чи можна підключити кілька клієнтів?**

Так. Кожен клієнт підключається окремо, усі підключення видно в кабінеті.

**Чи можуть співробітники підключати своїх агентів?**

Так, кожен співробітник підключається сам під своїм входом і отримує свої права. Власник бачить лише свої підключення.

**Чи може агент щось зламати?**

Агент виконує лише ті операції, які доступні вам у проєкті, і перепитує перед деструктивними операціями. Нове створюється вимкненим, доки ви не перевірите.

**Це платно?**

Ні, MCP-сервер входить у ваш тариф Zenedu. Оплата клієнта, наприклад Claude або ChatGPT, залежить від його умов.

**Як відключити агента?**

Відкрийте **Налаштування → Акаунт → MCP** і відкличте підключення. Клієнт одразу втратить доступ.
