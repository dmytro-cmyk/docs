---
title: "Отримати платіжну систему"
description: "Повертає одну платіжну систему за ID"
openapi: "GET /api/v1/payment-systems/{paymentSystem}"
---

Повертає одну платіжну систему акаунта. На платіжну систему іншого акаунта повернеться `404`.

Дані доступу ніколи не повертаються: автоматичні типи повідомляють лише `credentials_set`.
