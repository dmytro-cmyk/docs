---
title: "Створити платіжну систему"
description: "Створює платіжну систему в акаунті"
openapi: "POST /api/v1/payment-systems"
---

Створює платіжну систему вказаного `type`.

- Ключі `settings` залежать від `type`, див. таблицю в полі `settings`. Невідомі ключі відкидаються, у текстових значень обрізаються пробіли.
- `name` має бути унікальним в акаунті без урахування регістру.
- В акаунті може бути лише одна платіжна система `telegramstars`: на другу повернеться `409`.
- Для `manually` у реквізитів обов’язкові `name` і `value`, а підсумкове повідомлення бота має вміститися в 4000 символів.
- `attach_to_all_offers` додає платіжну систему в усі тарифи, чию валюту та мінімальну суму вона підтримує.

<Warning>
Для `stripe` перед збереженням у Stripe реєструється вебхук із переданим `secret_key`. Якщо Stripe відхиляє ключ, нічого не зберігається і повертається `422` з помилкою в `settings.secret_key`.
</Warning>
