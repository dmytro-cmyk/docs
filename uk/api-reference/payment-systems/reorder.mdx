---
title: "Змінити порядок платіжних систем"
description: "Задає порядок відображення платіжних систем"
openapi: "PUT /api/v1/payment-systems/order"
---

Задає порядок відображення платіжних систем і повертає список у новому порядку. Кожен ID має належати цьому акаунту, інакше повертається `422` і порядок не змінюється.
