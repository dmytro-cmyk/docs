---
title: "Змінити порядок способів оплати"
description: "Задає порядок відображення способів оплати"
openapi: "PUT /api/v1/payment-systems/order"
---

Задає порядок відображення способів оплати і повертає список у новому порядку. Кожен ID має належати цьому акаунту, інакше повертається `422` і порядок не змінюється.
