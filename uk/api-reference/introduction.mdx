## Базовий URL

Усі ендпоінти API v1 використовують базовий URL:

```
https://app.zenedu.com/api/v1
```

## Авторизація

API v1 використовує авторизацію за Bearer-токеном. Передавайте токен у кожному запиті:

```bash
curl -X GET https://app.zenedu.com/api/v1/bots \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Accept: application/json"
```

<Warning>
  Заголовок `Accept: application/json` обов’язковий для всіх запитів до API v1.
</Warning>

Створіть API-токен в особистому кабінеті Zenedu в налаштуваннях акаунта. Токен показується лише один раз — збережіть його в надійному місці.

## Ендпоінти Pro

Деякі ендпоінти потребують активної підписки Pro. У документації вони позначені позначкою **(Pro)**. Виклик Pro-ендпоінта без активної підписки повертає `403 Forbidden`.

## Пагінація

Ендпоінти-списки повертають посторінкові відповіді з полями `data`, `links` і `meta`. Розмір сторінки задається параметром `per_page` (за замовчуванням 30).
