---
title: "MCP-сервер"
description: "Підключіть ШІ-агентів до акаунта Zenedu через Model Context Protocol"
---

Zenedu надає [MCP](https://modelcontextprotocol.io)-сервер для ШІ-агентів. Підключений агент може створювати курси та воронки, керувати підписниками й доступами, тарифами, замовленнями, розсилками, автоматизаціями та налаштуваннями ботів. Агент зможе виконати будь-яку дію, яку раніше ви робили руками в кабінеті.

## Адреса

```
https://app.zenedu.io/mcp
```

Транспорт: Streamable HTTP.

## Швидке налаштування

Скопіюйте промпт і надішліть його своєму ШІ-агенту: Claude, ChatGPT, Cursor або будь-якому іншому. Агент сам додасть сервер, вам залишиться підтвердити підключення та увійти в Zenedu.

```
Додай MCP-сервер Zenedu https://app.zenedu.io/mcp
```

## Авторизація

**OAuth.** Додайте адресу як конектор у своєму клієнті. Під час першого підключення клієнт відкриє сторінку Zenedu: увійдіть, виберіть проєкт і натисніть **Дозволити**. Агент працюватиме в межах ваших прав у цьому проєкті.

**MCP-токен.** Для клієнтів без OAuth (n8n, скрипти) створіть токен в особистому кабінеті: **Налаштування → Акаунт → MCP → Створити токен**. Токен показується один раз, скопіюйте його одразу. Передавайте його в заголовку `Authorization: Bearer YOUR_MCP_TOKEN`.

Усі підключення й токени видно на тій самій вкладці **MCP**, там же будь-яке з них можна відкликати.

## Підключення клієнта

<Tabs>
  <Tab title="Claude">
    **Claude Code**

    ```bash
    claude mcp add --transport http zenedu https://app.zenedu.io/mcp
    ```
    Потім виконайте `/mcp` у Claude Code, виберіть `zenedu` і увійдіть у Zenedu в браузері. Після цього попросіть Claude, наприклад: *«Покажи мої боти і створи воронку з трьома привітальними повідомленнями в першому».*

    **Claude Desktop і claude.ai**

    Відкрийте **Settings → Connectors → Add custom connector**, вкажіть назву `Zenedu` і адресу `https://app.zenedu.io/mcp`, потім натисніть **Connect** і дозвольте доступ.
  </Tab>
  <Tab title="ChatGPT">
    **ChatGPT у браузері та десктопі**

    Увімкніть режим розробника в **Settings → Apps & Connectors → Advanced settings**, потім створіть конектор з адресою `https://app.zenedu.io/mcp` і автентифікацією *OAuth* та дозвольте доступ.

    **Codex**, агент ChatGPT для термінала та IDE:

    ```bash
    codex mcp add zenedu --url https://app.zenedu.io/mcp
    codex mcp login zenedu
    ```

    Інструменти з’являться в кожній сесії Codex, у CLI та в розширенні для IDE.
  </Tab>
  <Tab title="Cursor">
    Додайте в `.cursor/mcp.json` проєкту або в глобальні налаштування MCP у Cursor:

    ```json
    {
      "mcpServers": {
        "zenedu": {
          "url": "https://app.zenedu.io/mcp"
        }
      }
    }
    ```

    Потім натисніть **Connect** біля `zenedu` в налаштуваннях MCP у Cursor і дозвольте доступ.
  </Tab>
  <Tab title="n8n">
    Додайте ноду **MCP Client Tool** у воркфлоу з AI Agent: адреса `https://app.zenedu.io/mcp`, транспорт *HTTP Streamable*, авторизація *Header Auth* із заголовком `Authorization` і значенням `Bearer YOUR_MCP_TOKEN`. Виберіть інструменти, доступні агенту, або дозвольте всі.
  </Tab>
  <Tab title="DeepSeek">
    Агентський harness DeepSeek `dsh` (репозиторій `deepseek-ai`, developer preview) підключає MCP-сервери через плагін `@deepseek-ai/dsh-mcp-client`. Додайте в `~/.dsh/profiles/web/cordis.patch.yml`:

    ```yaml
    insert:
      - id: zenedu
        name: '@deepseek-ai/dsh-mcp-client'
        config:
          serverName: zenedu
          transport: streamable-http
          url: https://app.zenedu.io/mcp
          headers:
            Authorization: !!js process.env.ZENEDU_MCP_TOKEN_HEADER
    ```

    і експортуйте `ZENEDU_MCP_TOKEN_HEADER="Bearer YOUR_MCP_TOKEN"` перед `pnpm dsh web`. Будь-який інший MCP-клієнт із моделлю DeepSeek (Cherry Studio, Cline, Continue) підключається так само: тип сервера *Streamable HTTP*, адреса та OAuth або заголовок `Authorization` з MCP-токеном.
  </Tab>
</Tabs>
