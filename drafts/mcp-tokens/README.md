# MCP-токены (скрыто)

Персональные MCP-токены («Настройки → Аккаунт → MCP → Создать токен») пока скрыты в кабинете,
поэтому в публичной доке MCP описан только OAuth.

Здесь лежат полные версии страниц с токенами (OAuth + токен), en/uk/ru:

- `mcp.mdx`, `uk/mcp.mdx`, `ru/mcp.mdx` — раздел «Авторизация» с абзацем про MCP-токен,
  вкладки n8n и DeepSeek (подключение через `Authorization: Bearer YOUR_MCP_TOKEN`).
- `authentication.mdx`, `uk/authentication.mdx`, `ru/authentication.mdx` — строка «OAuth или MCP-токен».

Чтобы вернуть: скопировать файлы поверх страниц в корне репо и сверить с тем, что менялось после.
