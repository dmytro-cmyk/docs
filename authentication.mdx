---
title: "Authentication"
description: "How to authenticate with the Zenedu API"
---

API v1 uses Bearer token authentication.

## Getting your token

Find your API token in the Zenedu dashboard under **Workspace settings → API & Webhooks**. Resetting the token there invalidates the previous one. Keep the token secret: it gives full access to your account.

## Using the token

Include the token in the `Authorization` header of every request:

```bash
curl -X GET https://app.zenedu.com/api/v1/bots \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Accept: application/json"
```

<Warning>
  The `Accept: application/json` header is required for all API v1 requests. Requests without this header will be rejected.
</Warning>

## Pro features

Some endpoints require an active Pro subscription. These are marked with a **Pro** badge in the documentation. Calling a Pro endpoint without an active subscription returns a `403` error.
