---

API v1 uses Bearer token authentication.

## Getting your token

Find your API token in the Zenedu dashboard: **Settings → Workspace → API & Webhooks**. Resetting the token there invalidates the previous one. Keep the token secret: it gives full access to your account.

The [MCP server](/mcp-server) for AI agents connects through OAuth.

## Using the token

Include the token in the `Authorization` header of every request:

```bash
curl -X GET https://app.zenedu.io/api/v1/bots \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

<Note>
  API v1 returns JSON by default. The `Accept: application/json` header is optional. File downloads return the file content, and `204` responses have no body.
</Note>
